# ✈️ Росавиатест: Специалист по техническому обслуживанию ВС (Категория 17)

Полностью автономный офлайн-тренажёр для подготовки к сдаче официального квалификационного экзамена Росавиации.

🚀 **Онлайн-версия:** [Запустить тренажёр](https://kiberzefirka.github.io/rosaviatest-custom/)

---

## 📌 Особенности тренажёра

- **100% официальная база Росавиации:** 609 вопросов с точной нумерацией сайта (№ 60 — № 1398).
- **1:1 соответствие ключам Росавиации:** система оценивания полностью синхронизирована с официальным экзаменационным ПО.
- **Полная автономность:** всё приложение упаковано в единый файл без внешних зависимостей, библиотек и серверов. Работает без интернета.
- **15 билетов по 41 вопросу:** продуманная разбивка всей базы без дублирования.
- **Радар знаний по 13 темам:** аналитика успеваемости по каждой предметной области (включая разбивку масштабной Темы № 5 на 6 частей).
- **Режимы обучения:**
  - 📋 **Билеты** — тренировка блоками по 41 вопросу.
  - 🏃 **Марафон** — последовательное прохождение всех 609 вопросов с сохранением прогресса.
  - ⏱️ **Генеральный экзамен** — симуляция реальной аттестации (40 минут, проходной балл 75%).
  - 🎯 **Отработка ошибок** — автоматический сбор неверных ответов в персональный список.
  - 🔍 **Поиск по базе** — мгновенный фильтр по ключевым словам и номерам вопросов.
- **Эргономика и дизайн:**
  - Поддержка тёмной 🌙 и светлой ☀️ тем.
  - Адаптация под экраны смартфонов (iPhone и Android).
  - Звуковые эффекты на чистом Web Audio API.

## 📱 Как установить на телефон (как приложение)

1. Откройте ссылку тренажёра в браузере телефона (**Safari** на iOS или **Chrome** на Android).
2. Нажмите кнопку **«Поделиться»** (в Safari) или **«Меню (три точки)»** (в Chrome).
3. Выберите пункт **«На экран "Домой"»** (Add to Home Screen).
4. На экране появится иконка ✈️, и тренажёр будет открываться на весь экран даже без доступа к интернету!
